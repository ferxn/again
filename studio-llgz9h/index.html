Edits are saved straight to your GitHub repo. The public site updates 1 to 2 minutes after each save.

Connect

Create a fine-grained token at GitHub > Settings > Developer settings > Personal access tokens. Limit it to this one repo with Contents set to read and write. The token stays in this browser and is only sent to api.github.com.
